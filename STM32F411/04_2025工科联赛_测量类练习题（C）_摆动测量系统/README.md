> **没有找到对应的赛题**。从代码看是"单摆 / 悬挂物参数测量"：测摆长 L、测周期 T、测摆角、测经过次数。

## 硬件

- STM32F411CEU6
- JY61P（USART2，115200）：取 Yaw 和 Z 轴角速度 Gyro
- HC-SR04 超声波：Trig PB4 / Echo PB5，TIM2 计数测回波时间
- 红外对管 ×3：BZ1 PB7、BZ2 PC14、BZ3 PB8
- OLED、蜂鸣器 PB10、LED PB12、按键（PA6, PA7, PB0, PB1）
- 上位机 / 串口屏：USART6（PA11 TX / PA12 RX）

## 用法：USART6 发单字符选题，结果从 USART6 回传

| 字符 | 题 | 做法 |
|---|---|---|
| `e` | 初始化 | IMU 校零，超声波测一次基准距离 `L_raw = 67 − d − 12.2` |
| `a` | 第二题：测摆长 L | Yaw 接近 0（摆到最低点）时取超声波最小距离，`L = L_raw + (67 − min − 12.2) / 100` |
| `b` | 第三题：测周期 T | 角速度过零计次，两次过零间隔 × 2 = T（小于 1 s 的结果丢掉） |
| `c` | 第四题：测角度 | `h = 68 − L − 12.2 − d`，`a = atan(h / 50) × 180 / 3.14 + 2`，取多次平均，回传 `angle` / `ave_angle` |
| `d` | 第五题：计数 | 三个红外下降沿计数，回传次数 |

`67`、`12.2`、`50`、`+2` 都是按自己的支架尺寸标出来的常数，换了装置要重新量。
