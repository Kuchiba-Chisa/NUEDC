# 2025 校赛 D1 题 智能声光追踪巡检小车（STM32F411，2025 年 5 月）

题目见 [D1题 智能声光追踪巡检小车.pdf](D1题%20智能声光追踪巡检小车.pdf)。底盘代码沿用 [2024H 自动行驶小车](../01_2024H_自动行驶小车) 的 `clean` 工程。

`final_5.4` 是 05-04 校赛结束时的版本（从 `5.4_final2.zip` 里取出来的）。原来的文件夹在 7 月又被改过，所以没有用它。
用 Keil 5 编译通过，0 error。

## 硬件

- STM32F411CEU6
- 编码器电机 ×2 + 双路驱动；感为 8 路灰度（I2C 版，软件 I2C）；JY61P 陀螺仪
- HC-SR04 超声波（检测障碍物 / 目标距离）
- 红外避障对管 ×2（BZ、BZ2，代码里读取的部分已注释，改用超声波）
- 蜂鸣器（声提示）
- K210 / K230 视觉（USART1）

## 引脚（来自 `clean.ioc`）

| 功能 | 引脚 | 外设 |
|---|---|---|
| 电机 PWM | PA8, PA9, PA10, PA11 | TIM1_CH1–4 |
| 编码器 | PB6/PB7、PA0/PA1 | TIM4、TIM5 |
| JY61P | PA2 TX / PA3 RX | USART2，DMA + 空闲中断 |
| 视觉 | PA15 TX / PB3 RX | USART1（`User/USART/usart_2.c` 里的 `Usart2_SendChar` 实际走的是 `huart1`） |

| 灰度 | PB8 SCL / PB9 SDA | 软件 I2C |

| 按键 KEY0–4 | PA12, PA6, PA7, PB0, PB1 | EXTI |

## 任务（`Core/Src/main.c`，按键选 Flag）

**Flag 1：巡检主流程。** 启动时蜂鸣器响 3 声，然后灰度 PID 循迹，用状态变量 `crossflag`、`bzflag` 推进流程：

1. 到 B 点（`crossflag == 1`）：用 IMU 原地转到 Yaw = −70°，停下响 3 声，`BASE_SPEED` 提到 4000
2. `bzflag 1`：超声波测到 8–20 cm 有障碍 → 减速到 2000，倒车直到两侧灰度离开黑线
3. `bzflag 2`：倒回十字路口 → 原地右转到 Yaw = 45°，长鸣一声
4. `bzflag 3`：再次测到 8–15 cm → 原地左转到 Yaw = −73° 掉头避障，长鸣一声
5. 8 路灰度全压线 → 到终点，停车响 3 声

**Flag 2**：给视觉发 `'0'`，用 IMU 锁 −63° 慢速直行，灰度中间压线时停下。
**Flag 3**：给视觉发 `'1'`（切换识别模式）。
**Flag 4**：只测距，调超声波用。

## 注意

- 转角 −70° / 45° / −73° / −63° 和距离阈值都是在校赛场地上标的，换场地要重新测。
- 转弯是 `while (Yaw > 目标) Set_PWM(...)` 的开环原地转，没有超时退出，IMU 数据断了会卡死。
