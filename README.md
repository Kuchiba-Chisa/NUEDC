国赛 TI 板题用 **MSPM0G3507**（CCS Theia + SysConfig）。每个工程目录下有单独的 README，写了用到的硬件、引脚和用法。

## 公共硬件

| 模块 | 型号 | 接口 |
|---|---|---|
| 主控 | STM32F411CEU6 核心板（外设例程里部分用 Nucleo-F411RE） / MSPM0G3507 LaunchPad | — |
| 陀螺仪 | 维特 JY61P | UART 115200，0x55 0x53 帧取 Yaw |
| 灰度 | 感为 8 路灰度（数字 GPIO 版 / 无 MCU 模拟版 / I2C 版） | GPIO / ADC+3 根地址线 / I2C |
| 电机 | 编码器直流减速电机 + 双路电机驱动（TB6612 类，代码里没写型号） | 4 路 PWM + 2 路编码器定时器 |
| 步进 | 42 步进 + 驱动器（脉冲/方向/使能）；WHEELTEC MS42DDC 驱控一体（串口） | TIM PWM / UART 9600 |
| 显示 | 0.96 寸 OLED（SSD1306，I2C） | 软件/硬件 I2C |
| 视觉 | K210 / K230 / MaixCam（串口发 `x,y\r\n` 或单字符命令） | UART |

## 编译环境

- STM32：Keil MDK 5（ARMCC V5.06）+ `Keil.STM32F4xx_DFP 2.17.1`。工程里的 `Drivers` 已经精简，只留了 F411 的头文件；
  要改外设配置，用 CubeMX 打开 `.ioc` 重新生成就行。
- 部分源文件是 GBK 编码（Keil 默认），用 VS Code 打开中文乱码时把编码切成 GB2312。
- MSPM0：CCS 20.x + `mspm0_sdk_2_04_00_06` + SysConfig 1.22。CCS 里 Import Project 选工程目录即可，`Debug/` 会重新生成。

## 第三方代码说明

工程里用到的部分驱动来自厂商例程或开源项目，版权归原作者：
感为灰度驱动（0BSD）、维特 JY61P 协议、江协科技 OLED 驱动、中景园 OLED 驱动、TI MSPM0 SDK 模板（BSD-3）、ST HAL 库（BSD-3）。
`STM32F103/01_2023E` 整体基于 DuRuofu 的 `STM32_Target_Tracking_System`；STM32F411 小车早期的按键 / 应用框架（`key.c`、`app.c`）也来自这个项目。
