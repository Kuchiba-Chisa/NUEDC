> 带舵机 PWM 和视觉串口。云台部分用 STM32 做，见 [STM32F411/03_2025E_简易自行瞄准装置_步进云台](../../STM32F411/03_2025E_简易自行瞄准装置_步进云台)。

## 硬件

- MSPM0G3507 LaunchPad（时钟走 SYSPLL）
- 编码器直流电机 ×2 + 双路驱动（每个电机两路 PWM：一路固定 10000，一路给 10000∓速度，是"慢衰减"驱动方式）
- 感为 8 路灰度，**I2C 版**（最终版用 `IIC_Get_Digtal()` 读 8 位数字量；`No_Mcu_Ganv_*` 无 MCU 版的代码还在，但已注释掉）
- JY61P 陀螺仪（UART3 + DMA）
- MaixCam / K230（UART2 + DMA）
- 舵机 ×1（`SERVO_PWM_Set(angle)`，最终版没调用）
- OLED（软件 I2C）、蜂鸣器、按键 ×4

## 程序逻辑（`empty.c`）

1. **按 KEY4 设圈数**：每按一次 `num++`（在 `User/Encoder.c` 的 `GROUP1_IRQHandler` 里）。上电时 `num=0`，车不动。
2. `N < num` 时循环：
   - 读 8 路灰度 → `CalculateOffset` 按权重 ±3/±6/±9 算偏差 → 位置 PID（`Kp=1.5, Ki=0.01, Kd=0.2`）→ 差速；
   - 最右边探头压线、最左边没压（`turn==1`）→ 判定到直角弯：先直走 350 ms，然后原地左转，直到中间两个探头重新压线；
   - 每转 4 次弯 `N++`，即跑完一圈。
3. 基础速度 `BASE_SPEED = 3000`（满量程 10000），在 `User/pid.c` 里改。

## MAIX 协议

`"[x0,x1,...,x7,p0,...,p5]\r\n"`，14 个整数，解析到 `xunji[8]` 和 `panduan[6]`（`User/Imu.c` 的 `MAIX_ReceiveData`）。
最终版循迹只用灰度，没用这组数据。

## 注意

- JY61P 解析里有一段滤波：`Yaw>60` 或 `Yaw<-60` 就沿用上一次的值。这只适合小角度场景，要整圈转向的话必须删掉。
- CCS 工程名是 `G3507`，和 [02_方形循线小车](../02_方形循线小车_赛前练习) 重名，不能导入同一个 workspace。
