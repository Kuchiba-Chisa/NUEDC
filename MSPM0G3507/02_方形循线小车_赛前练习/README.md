# 方形循线小车（MSPM0G3507，2025 年 6–7 月赛前练习）

在 1 m 方形黑线框上循迹、过直角弯、计圈。这是国赛前猜题做的练习，后来直接拿来做了 2025 E 题的小车（见 [01_2025E](../01_2025E_简易自行瞄准装置_小车)）。

## 版本

| 目录 | 日期 | 说明 |
|---|---|---|
| `final_7.7` | 07-07（08-02 又改过） | **最终版**，三种模式 |
| `history/7.4_加PID` | 07-04 | 加入灰度位置 PID |
| `history/6.26_初版` | 06-26 | IMU + PWM + 按键的初版 |

都用 CCS 20.1 编译通过。CCS 工程名是 `G3507`，和 01_2025E 重名，不能导入同一个 workspace。

## 硬件和引脚

底盘和 [01_2025E 小车](../01_2025E_简易自行瞄准装置_小车/README.md#引脚来自-emptysyscfg) 一样：电机 PWM 用 TIMA0（PA8/PA9/PB20/PB24），
编码器 PA15/PA16、PB8/PB9，JY61P 接 UART3（PA25/PA26），OLED 接 PB2/PB3，按键 PA14/PA13/PA12/PA23，灰度 I2C 接 PA0/PA1。

`.syscfg` 里另外配了一组 8 路 GPIO 灰度（PB7, PB6, PA17, PA18, PA24, PA27, PA31, PA28），但代码里实际用的是 I2C 版（`IIC_Get_Digtal`）。

## 按键（`User/Encoder.c`）

| 按键 | 作用 |
|---|---|
| KEY1 (PA14) | `num++`，设置圈数 |
| KEY2 (PA13) | 模式 2：跑 `num` 圈后停 |
| KEY3 (PA12) | 模式 3：同模式 2，每次转弯给上位机发字符 |
| KEY4 (PA23) | 模式 4：固定跑 4 圈 |

## 转弯和计圈

- `CalculateOffset` 发现最右侧探头压线、最左侧没压 → `turn = 1`，判定到了直角弯
- 先直走一小段（让车轴对准拐点），然后原地左转 `Set_PWM(-3000, 3000)`，直到中间两路重新压线
- 转 4 次弯 = 一圈。跑完最后一圈后再转一次，回到出发方向停下

## 串口（模式 3）

用 JY61P 那个 UART（`uart0_send_char` 实际走的是 `Imu_INST`，即 UART3 TX）发单字符：
转弯时发 `'1'`，转完发三个 `'0'`。注释里写的"竖线发 2、远横线发 3、近横线发 4"，对应代码已经注释掉了。
